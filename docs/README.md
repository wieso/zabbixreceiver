# Карта документации

[Обзор проекта и быстрый старт](../README.md)

Документация описывает текущую рабочую копию. Для опубликованного релиза читайте документы того же тега. Каждая тема имеет одно основное место описания:

| Где читать и обновлять | Что здесь хранится |
| --- | --- |
| [README проекта](../README.md) | Назначение, короткий старт и ссылки на руководства |
| [configuration.md](configuration.md) | Параметры, значения по умолчанию, валидация, аутентификация, поведение API/Streaming, метрики и ошибки |
| [metadata.md](metadata.md) | Теги, группы, выбранный inventory, формат лейблов и API-обогащение Streaming |
| [deployment.md](deployment.md) | Установка, демонстрация, коннектор Zabbix, служба, контейнеры, сеть, секреты и диагностика |
| [architecture.md](architecture.md) | Карта кода, потоки данных, состояние и границы компонентов |
| [scaling.md](scaling.md) | Ресурсы, измерения, шардирование API, балансировка Streaming и демо с несколькими коллекторами |
| [development.md](development.md) | Команды проверок, CI, интеграция OCB и выпуск артефактов |
| [README модуля](../receiver/zabbixreceiver/README.md) | Подключение приёмника через OCB и совместимость версий |

При изменении поведения обновляйте соответствующий раздел и исполняемые примеры в `configs/`, `examples/` или `deployments/`. В других документах оставляйте краткое пояснение и ссылку вместо копии правил или команд. Проверки документации должны обращаться к основному руководству темы.

README релизного архива содержит также ссылки на материалы исходного репозитория: для работы без исходников достаточно вложенных `docs/configuration.md`, `docs/metadata.md`, `docs/deployment.md` и `configs/`.

## Исторические материалы

[Планы и проектные решения](superpowers/README.md) сохраняют контекст прошлых работ. Они могут содержать старые версии, пути, копии кода и инструкции для конкретной задачи. Их не нужно синхронизировать с текущим продуктом или использовать как действующий справочник. При расхождении актуальных руководств с реализацией сверяйтесь с кодом и тестами и исправляйте основное руководство.
