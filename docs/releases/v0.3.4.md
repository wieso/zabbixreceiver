# v0.3.4 — оба представления групп по умолчанию

Значение по умолчанию для `metadata.host_groups_format` изменено с `names` на `both`. В API и Streaming без дополнительной настройки передаются одновременно:

```text
host_groups="Linux, Production"
host_group_linux="true"
host_group_production="true"
```

Явные настройки `names`, `flags` и `both` сохраняют прежнее поведение. `metadata.enabled: false` отключает метаданные, включая оба представления групп.

## Переход с v0.3.3

Если формат не указан, после обновления добавятся лейблы `host_group_*`. Это создаёт новые серии; исторические серии сохраняются. Чтобы оставить только `host_groups`, укажите:

```yaml
receivers:
  zabbix:
    metadata:
      host_groups_format: names
```

Другие метаданные и версии зависимостей не меняются.
