# v0.3.3 — выбор представления групп хоста

Добавлена настройка `metadata.host_groups_format` для API и Streaming:

- `names` (по умолчанию): `host_groups="Linux, Production"`.
- `flags`: `host_group_linux="true"` и `host_group_production="true"`.
- `both`: оба представления одновременно.

```yaml
receivers:
  zabbix:
    metadata:
      host_groups_format: both
```

`host_groups` сохраняет исходные названия, сортирует их и удаляет точные дубликаты. Суффиксы `host_group_*` нормализуются как ключи тегов; при совпадении получается один флаг. Без групп лейблы не добавляются. `metadata.enabled: false` отключает оба представления. Неверный формат отклоняется при валидации конфигурации.

## Переход с v0.3.2

Без изменения конфигурации сохраняется формат `host_groups`. Чтобы получить оба варианта, укажите `both`; для прежних флагов — `flags`. Смена формата создаёт новые серии и может потребовать обновления панелей и запросов. Исторические серии сохраняются. Другие метаданные и зависимости не меняются.
