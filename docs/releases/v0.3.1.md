# v0.3.1 — названия групп в значении лейбла

Группы хоста передаются в одном строковом лейбле `host_groups` вместо отдельных `host_group_*="true"`. Изменение применяется к API и Streaming.

```text
host_groups="Linux, Production, Серверы/Москва"
```

Исходные названия сохраняют регистр, пробелы, Unicode и пунктуацию. Названия сортируются, точные дубликаты удаляются и соединяются через `, `. При отсутствии групп лейбл не добавляется. Запятые в названиях не экранируются: значение предназначено для чтения, а не обратимого разбора списка.

## Переход с v0.3.0

Обновите запросы и панели, использующие `host_group_*`. Для хоста с единственной группой `Linux` фильтр `{host_group_linux="true"}` заменяется на `{host_groups="Linux"}`. Если групп несколько, значение содержит весь список; точное сравнение с одной группой такой хост не выберет.

Замена лейблов создаёт новые серии. Исторические серии остаются со старыми лейблами. Остальные метаданные, значения метрик и timestamps не меняются.
