# Приёмник Zabbix для OpenTelemetry Collector

Нативный приёмник `zabbix` получает числовые элементы данных через опрос Zabbix API или HTTP Streaming и преобразует их в метрики OpenTelemetry типа gauge. Готовая сборка `otelcol-zabbix` отправляет их в VictoriaMetrics через стандартный экспортёр Prometheus remote-write. Приёмник можно включить и в собственную сборку Collector.

Документация описывает текущую рабочую копию, включая Streaming. Возможности опубликованного релиза следует сверять с его версией документации.

## Быстрый старт

Для знакомства с обоими режимами используйте демонстрацию. Требуются Docker Engine и Compose v2.24 или новее:

```bash
make demo-up
make demo-verify
```

Grafana с готовым [дашбордом мониторинга ресивера](http://127.0.0.1:3000/d/zabbix-receiver) доступна без входа после запуска. Адреса интерфейсов, запросы для сравнения метрик и настройка портов приведены в [руководстве по демонстрации](docs/deployment.md). После работы выполните `make demo-down`: команда удалит контейнеры и все данные демонстрации, включая токены.

Для подключения к своим сервисам выберите способ установки ниже и настройте [API](docs/configuration.md) или [Streaming](docs/configuration.md). Оба режима используют общие правила имён и лейблов. Без API-обогащения Streaming берёт имя метрики из названия элемента и не получает часть атрибутов API; перед переключением проверьте [совместимость Streaming](docs/configuration.md#режим-streaming).
